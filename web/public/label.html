Shortcuts & conventions
  • ← / → — previous / next image
  • u r f d l b — select face, start placing
  • click 4× on canvas — place that face's corners going around the face
  • click a marker (no face selected) — pick it up, next click drops it
  • placing/dropping near another face's marker — snaps to it, so shared corners coincide exactly
  • "Suggest (model)" — pre-fills unlabeled faces with the current model's guess; verify positions and fix by picking markers up. Needs the deployed site (not a local file).
  • Esc — cancel in-progress face
  • Delete or "Clear face" — remove selected face's label
  • mouse wheel — zoom toward cursor
  • middle-drag, or space+drag — pan
  • 0 — reset zoom/pan to fit image
Corner order: just go around the face — start at any corner, either direction. The only wrong order is a zigzag (crossing the face diagonally mid-way), which draws a bowtie instead of a quad. Which face it is comes from its center color (white=U, red=R, green=F, yellow=D, orange=L, blue=B). Rounded/stickerless corners: click the outermost point of the plastic itself; don't extrapolate past the edge. Corners hidden by fingers or objects: estimate and click anyway; corners off the frame edge go outside the image. Label every face whose center you can identify.
